## ARQUITECTURA MVC ESTRICTA

### MODELO (models/database.py):
**Responsabilidad única:** Interacción con base de datos

**Métodos principales:**
- `get_all_productos()` - Obtiene todos los productos
- `get_all_almacenes()` - Obtiene todos los almacenes
- `agregar_producto()` - Inserta nuevo producto
- `eliminar_producto()` - Elimina producto por ID
- `agregar_almacen()` - Inserta nuevo almacén
- `eliminar_almacen()` - Elimina almacén por ID
- `validar_usuario()` - Autenticación con hash SHA256
- `almacen_existe()` - Valida IDs de almacén

**Reglas estrictas:**
- NUNCA importa tkinter o módulos de UI
- Solo maneja datos y conexión SQLite
- Retorna listas/tuplas, nunca widgets

### VISTA (views/main_view.py):
**Responsabilidad única:** Crear y gestionar interfaz de usuario

**Componentes principales:**
- Frame de Inicio con logo UNISON y navegación
- Frame de Productos con Treeview y formulario
- Frame de Almacenes con Treeview y formulario
- Sistema de scroll responsivo
- Efectos hover y styling

**Métodos públicos:**
- `show_frame(frame_name)` - Navegación entre pantallas
- `update_productos_tree(productos)` - Actualiza tabla productos
- `update_almacenes_tree(almacenes)` - Actualiza tabla almacenes
- `get_producto_data()` - Obtiene datos del formulario
- `get_almacen_data()` - Obtiene datos del formulario
- `limpiar_formulario_*()` - Limpia formularios

**Reglas estrictas:**
- NUNCA importa sqlite3 o hace consultas DB
- Solo crea widgets y maneja eventos UI
- No contiene lógica de negocio

### CONTROLADOR (controllers/integrated_controller_simple.py):
**Responsabilidad única:** Coordinación entre Modelo y Vista

**Flujo principal:**
1. Inicialización con login obligatorio
2. Validación de credenciales contra BD
3. Navegación a aplicación principal
4. Coordinación CRUD con validaciones

**Métodos principales:**
- `handle_login()` - Procesa autenticación
- `show_main_application()` - Inicia app principal
- `agregar_producto()` - Coordina inserción con validaciones
- `eliminar_producto()` - Coordina eliminación con confirmación
- `agregar_almacen()` - Coordina inserción de almacenes
- `eliminar_almacen()` - Coordina eliminación de almacenes
- `load_*_data()` - Carga datos del modelo a la vista

## VALIDACIONES Y MANEJO DE ERRORES

### Validaciones de Producto:
```python
- Nombre: obligatorio, max 100 chars
- Precio: obligatorio, float >= 0
- Cantidad: obligatorio, int >= 0  
- Departamento: obligatorio, max 50 chars
- Almacén: obligatorio, int > 0, debe existir en BD
```

### Validaciones de Almacén:
```python
- Nombre: obligatorio, max 50 chars, regex pattern
- Solo caracteres alfanuméricos, espacios, guiones
```

### Manejo de Errores:
- Try-catch en todas las operaciones de BD
- Mensajes de error descriptivos al usuario
- Logging de errores en consola para debug
- Rollback automático en transacciones fallidas

## PATRONES DE CÓDIGO Y CONVENCIONES

### Inicialización MVC:
```python
class IntegratedController:
    def __init__(self, root):
        self.model = DatabaseModel()        # Modelo
        self.view = MainView(root)          # Vista  
        self.setup_button_commands()        # Conectar eventos
```

### Patrón de carga de datos:
```python
def load_productos_data(self):
    productos = self.model.get_all_productos()  # Pedir al modelo
    self.view.update_productos_tree(productos)  # Actualizar vista
```

### Patrón de operaciones CRUD:
```python
def agregar_producto(self):
    data = self.view.get_producto_data()        # Obtener de vista
    if self.validar_producto(data):             # Validar en controlador
        if self.model.agregar_producto(...):    # Ejecutar en modelo
            self.load_productos_data()          # Refrescar vista
```
